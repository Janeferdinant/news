# Day 5: Designing and Evaluating AI-Driven Teaching Interventions

**What this folder is.** A small teaching example for a course on designing and evaluating AI-driven teaching interventions: a two-group (control and AI-tool) pre/post-test dataset, an analysis notebook and a static report page. It is separate from the fake-news detection demo in the rest of this repository.

> **The data is synthetic.** Every score and student id in `intervention_data.csv`, in `assets/plot.js` and on `report.html` is randomly generated by `regenerate_marks.py` from a fixed seed. No real student marks or names are stored here, and nothing in this folder is evidence about any real class or about how well an AI tool works.

## Contents
- `regenerate_marks.py`: seeded generator (Python standard library only). Rewrites `intervention_data.csv`, the chart data in `assets/plot.js` and the summary sentence in `report.html` so that they always agree.
- `intervention_data.csv`: `student_id, group, pre_score, post_score` (10 control and 10 AI students by default; ids are just 1 to N).
- `intervention_analysis.ipynb`: group statistics and a boxplot of learning gains (`assets/gain_boxplot.png`). Run it from this folder.
- `report.html`: static report with the boxplot image and an interactive Plotly chart.

## Regenerate the data
From the repository root:

```bash
python week1_day5_ai_interventions/regenerate_marks.py                  # seed 42, 10 per group
python week1_day5_ai_interventions/regenerate_marks.py --seed 7 --per-group 15
```

The same seed always gives byte-identical files. In the synthetic world the AI group is told to gain 6 points on average and the control group 2 (spread 3, before clipping to 0 to 100), so a difference between the groups is built in. Re-run the notebook afterwards to refresh `assets/gain_boxplot.png` and the notebook's outputs (needs `pandas` and `matplotlib`).
